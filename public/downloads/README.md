# Hyper Desktop Client Installer Downloads Folder

Drop your production builds in this folder:
- MacOS installer: `hyper-mac.dmg` or `hyper-mac.zip`
- Windows installer: `hyper-windows.exe` or `hyper-windows.msi`

They will be served statically from the URL path:
- MacOS: `/downloads/hyper-mac.dmg`
- Windows: `/downloads/hyper-windows.exe`

These files are hosted through GitHub and served directly via Netlify.
